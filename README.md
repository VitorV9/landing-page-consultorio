# 🩺 Consultório Valentina - Landing Page

Este é um projeto de uma landing page responsiva para uma clínica médica ("Consultório Valentina"), desenvolvido como atividade prática de desenvolvimento front-end. O objetivo da aplicação é demonstrar um exemplo de landing page com o uso de Bootstrap, retratando um estilo de landing page para consultorios.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica da página.
- **CSS3**: Estilização, layout flexível (Flexbox) e design responsivo.
- **Bootstrap 5**: Sistema de Grid responsivo, componentes nativos (Carrossel, Navbar, Abas/Pills) e classes utilitárias.

## 🔗 Link do Projeto
O site está hospedado na Vercel e pode ser acessado no link abaixo:

## 🛠️ Como executar o projeto localmente
1. Clone o repositório: `git clone https://github.com/VitorV9/landing-page-consultorio.git
2. Abra a pasta do projeto no seu editor de código.
3. Abra o arquivo `index.html` no seu navegador (ou use a extensão Live Server).
